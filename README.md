# TransLution fork of sqlstyle.guide

This is TransLution's fork of Simon Holywell's SQL style guide (`treffynnon/sqlstyle.guide`,
CC BY-SA 4.0). TransLution has made **no content changes** to it. The guide is one of the
cited sources for TransLution's SQL house style, which lives in `translution-wiki`
(`wiki/concepts/sql-style-conventions.md`). **Where the two disagree, the house style wins.**

- **Start here:** [`reference/README.md`](reference/README.md), the knowledge base for the fork
- **Findings first:** [`reference/00-findings.md`](reference/00-findings.md)
- **Syncing from upstream:** [`reference/01-repository/01-fork-and-upstream.md`](reference/01-repository/01-fork-and-upstream.md)
- **Offline copy:** `reference/navigator.html`, a single-file browsable copy of `reference/`.
  It is generated by `reference/_build/publish.ps1`; never edit it by hand.
- **Working rules:** [`AGENTS.md`](AGENTS.md), the contract for people and agents.
  `CLAUDE.md` imports it.
- **History and reasons:** [`CHANGELOG.md`](CHANGELOG.md)

Build: `bundle install && bundle exec jekyll serve` (Ruby). Checks:
`reference\_harness\Verify-Reference.ps1` and `reference\_harness\Test-LanguageWiring.ps1`.
Run `reference\_build\Install-Hooks.ps1` once per clone.

# SQL style guide

**[☛ Read the guide](https://www.sqlstyle.guide)**

---

## General

The guide is written in [Markdown][md-lang] and uses [Jekyll][jekyll] via
[GitHub's Pages][gh-pages] facility to render itself upon pushing to the `gh-pages`
branch.

## Sources

The markdown source for the guide can be found in [_includes/sqlstyle.guide.md][md]

## Installing for local development

There is a Gemfile supplied so you just need to follow the
[GitHub Pages documentation][gh-pages-help] to install the dependencies.

To then run it locally `bundle exec jekyll serve`
